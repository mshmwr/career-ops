# Frontend Engineer

## About KKTIX

KKTIX is one of the few ticketing platforms in Taiwan that can handle the concurrent load of a large-scale concert on-sale. We currently hold the country's record for average tickets sold per second. We're a SaaS event management platform serving organizers who run anything from small workshops to stadium tours, and frontend performance isn't an abstract concern here. Every on-sale, thousands of real users hit "buy" within the same millisecond.

## The Role

You'll join the team driving KKTIX's frontend evolution: incrementally migrating a production system that serves millions of users from a legacy Rails + AngularJS codebase into a modern React stack, without taking the site down. Every deploy goes live to organizers and ticket buyers, and the codebase carries years of business logic, edge cases, and accumulated traffic-handling tricks.

This isn't a greenfield project. We're looking for someone who enjoys taking a complex legacy system and making it maintainable, piece by piece, while it continues to serve production traffic.

## What You'll Do

- Develop and maintain KKTIX's web service across desktop web, mobile web, and in-app webpages, with performance under high load as a constant constraint
- Lead the migration of pages from our legacy Rails + AngularJS stack to React, with proper testing and gradual rollout
- Build internal dashboards and data visualizations to support decision-making for our team and organizers
- Write self-documented code with meaningful test coverage, and treat refactoring as part of day-to-day shipping
- Improve performance, accessibility, and code health across the codebase as you go

## Required

- 2+ years of professional web development experience
- Strong JavaScript, TypeScript, HTML, and modern CSS
- Production experience with React, Angular, or Vue.js (any modern component framework is fine)
- Practical experience with Tailwind CSS or an equivalent utility-first approach
- Production experience with a testing framework (Vitest / Jest + React Testing Library, or similar)
- Daily use of AI-assisted development tools (Claude Code, Cursor, GitHub Copilot, etc.) in your workflow
- Care about code quality, accessibility, and performance, and able to advocate for them in code reviews and design discussions
- Able to take a migration task from scoping to ship independently
- Comfortable working in legacy code, since refactoring is part of daily work here

## Nice to have

- Experience with large-scale refactors or legacy migrations on systems running in production without downtime
- Familiarity with i18n/l10n patterns in shipped applications, beyond translating string files
- Comfort with legacy frontend stacks (AngularJS V1, CoffeeScript, Sass, or any server-side template engine)
- Experience with Astro, Islands architecture, or SSR hydration patterns
- Frontend performance work: Core Web Vitals, bundle analysis, Lighthouse, real-user monitoring
- Familiarity with Ruby on Rails or Go on the backend
- Open source contributions, a personal portfolio, or a piece of code you're particularly proud of — we'd love to see it

## How We Work

We're a small team. Open discussion and mutual learning are how we get better, so we're looking for people who enjoy explaining their thinking, asking questions, and learning from teammates who know things they don't.
